# MASAR | مسار — منصة الطالب العمانية

تطبيق ويب كامل (Front-end فقط) لإنتاجية الطالب: منظّم مذاكرة، مهام، مكتبة ملخصات،
مدينة مسار التفاعلية، بوابات المدرسة (إدارة / معلم / ولي أمر / طالب) ومنطقة قيادة المالك.

**إعداد وتصميم:** عامر بن خلفان الشكيري / معاذ بن عامر الشكيري — @mo3th.x
جميع الحقوق محفوظة © MASAR مسار

## هيكل المشروع

```
masar-si/
├── index.html              الصفحة الرئيسية (نقطة الدخول)
├── manifest.webmanifest     بيانات التطبيق (PWA) — الاسم والأيقونات
├── .nojekyll               يمنع GitHub Pages من معالجة الملفات بـ Jekyll
├── css/
│   ├── style.css            التنسيقات الأساسية + قواعد الاستجابة (هاتف/كمبيوتر)
│   └── cloud.css            تنسيقات التزامن السحابي وشاشة الدخول ومنطقة القيادة
├── js/
│   ├── masar-data.js        البيانات الافتراضية والتخزين المحلي والتنقّل
│   ├── masar-cloud.js       محرّك المزامنة + حسابات الدخول + الأدوار
│   ├── masar-logo.js        مسارات الشعارات
│   ├── masar-sections.js    أقسام قابلة للتحكم + مدخل المالك السرّي
│   ├── masar-patch42.js     بوابة المالك السرّية + جدولي الخاص + حذف المهام
│   └── masar-patch43.js     تنبيهات الجدول + التصدير/الطباعة + إحصاءات المالك
└── assets/
    ├── logo.png             الشعار الدائري
    ├── logo-wide.png        الشعار العريض (الشريط العلوي للرئيسية)
    └── icon.png             أيقونة التطبيق (favicon / PWA / apple-touch-icon)
```

## التشغيل محلياً

لا يحتاج أي تثبيت — افتح `index.html` بالمتصفح.
وللتشغيل على خادم محلي (مستحسن لتجربة PWA):

```bash
python3 -m http.server 8000
# ثم افتح: http://localhost:8000
```

## النشر على GitHub Pages

1. Settings ← Pages
2. Source: **Deploy from a branch**
3. Branch: **main** — Folder: **/ (root)**
4. Save ← انتظر دقيقة ← الرابط: `https://amurmonth-gif.github.io/masar-si/`

> ملف `.nojekyll` موجود بالفعل، فلا حاجة لإضافته.

## ملاحظات تقنية

* التخزين: `localStorage` (المفتاح `MASAR_V3`) + `MASAR_CLOUD_STATE` / `MASAR_CLOUD_USERS`.
* المزامنة بين الأجهزة: تعمل عبر Firebase بعد وضع مفاتيح المشروع في `js/masar-cloud.js`
  (المتغيّر `FB_CONFIG`). بدون مفاتيح يعمل الموقع في «وضع العرض» (تزامن بين تبويبات الجهاز نفسه).
* الدخول: لا توجد شاشة «إنشاء حساب المالك» عند الفتح — الموقع يفتح مباشرة،
  وحساب المالك يُهيّأ صامتاً في الخلفية. الوصول إلى منطقة القيادة:
  زر «تسجيل الدخول» أو `#masar-owner-9k7` في نهاية الرابط.
* الخطوط (Noto Kufi Arabic / Cairo) تُحمّل من Google Fonts وتحتاج إنترنت في أول فتح.
